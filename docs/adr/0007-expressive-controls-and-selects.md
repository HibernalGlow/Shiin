# ADR-0007: Expressive 控件语法——禁止开关列表堆叠与原生 select

- **状态**：已接受 (Accepted)
- **日期**：2026-10-20
- **相关方**：Shiin 前端 / Xaihi 生态
- **关联**：ADR-0002（React + MD3 Expressive）

---

## 背景与问题

设置页与工作台在早期迭代里使用了两种与 Expressive 方向冲突的控件写法：

1. **简单开关列表堆叠**：把 `开机自启动 / 轻量模式 / 关闭行为 / 同名冲突` 这类设置逐行排成 `label + 原生 checkbox/switch`。它把层级压平成一张表单，缺少 Expressive 的块面、形状与状态反馈，也让“当前启用了什么”需要逐行阅读。
2. **原生 `<select>`**：系统下拉在 macOS/Windows/Linux 上外观、字号、圆角、动效完全不一致；在暗色 Expressive 主题上会出现系统白底菜单、不可控的焦点环和方向键行为，破坏形状与色阶。

用户反馈明确要求：设置 UI 优化，禁止简单开关列表堆叠，所有 select 自绘制；权限中心需要有独立入口并重写 UI。

## 决策

### 1. 禁止简单开关列表堆叠

- 同一组布尔设置**不得**渲染为多行 `switch row` 或 `checkbox row`。
- 必须使用以下 Expressive 形式之一：
  - **Connected Toggle Group**：2–4 个大尺寸 toggle（图标 + 标题 + 状态），选中项整块填充主色并发生形状/圆角变化；
  - **Connected Choice Group**：互斥选项（如关闭行为）使用连接式按钮组；
  - **Setting Tiles**：每个设置是一块可独立操作的 tile，而不是列表中的一行。
- 单个、孤立的布尔开关（例如某一个卡片内的附属开关）可以使用 switch，但不得与其它 switch 连续堆叠成列表。
- 应用示例：
  - 设置 → 启动与托盘：`开机自启动`、`轻量模式启动` 使用 Connected Toggle Group；`关闭主窗口`、`同名文件冲突` 使用自绘菜单。
  - 设置 → 快门声音：`悬浮通知` 使用单块 notify toggle；声音与位置使用自绘菜单。
  - 工作台 → 监听与自动化：三个布尔项使用 Connected Toggle Group。

### 2. 所有 select 必须自绘制

- 产品 UI 中**禁止**直接使用原生 `<select>` / `<option>`（包括 `<select className="...">`）。
- 统一使用 `BentoSelect`（`src/ui/components/bento-controls.tsx`）：
  - 触发器为按钮，展示当前值 + `chevronDown`；
  - 弹层使用 `surface-high` 容器、20px 圆角、Elevated 阴影；
  - 选中项使用 `primary-container` + check；
  - 支持 `default / chip / inline / notify` 四种视觉变体；
  - 支持点击外部关闭、`Escape` 关闭、`role="listbox"` / `role="option"` / `aria-selected`。
- 禁止使用“看起来像 select 的原生控件”再覆盖样式；必须由组件自己渲染触发器与菜单。
- 应用范围：工作台（显示器/窗口、保存方式、目标手柄）、设置（关闭行为、文件名冲突、快门音效、通知位置、界面语言）、后续新增的所有下拉。

### 3. 权限中心独立入口

- 权限诊断不再作为设置页的隐藏 sheet，改为顶层目的地 `权限`：
  - 侧栏 / 紧凑侧轨 / 底部 Dock 均提供入口；
  - 权限缺失时导航项显示 `!` 徽章；
  - 权限中心使用 Expressive 页面：大号 `n/4` 计数、波浪进度、形状权限块、截图实测、目录读写与手柄 HID 条。
- 设置页的权限摘要仍保留，点击“处理权限”跳转到权限中心；标题栏权限按钮同样跳转。

## 后果

- **正面**：
  - 开关与下拉在三个平台/三种窗口宽度下视觉一致；
  - 设置不再像后台表单，状态一眼可见；
  - 权限中心有稳定、可发现的入口。
- **代价**：
  - `BentoSelect` 需要自己维护弹层定位、外部点击、键盘与可访问性；
  - 设计评审需要检查“是否又出现了 switch 列表”或“原生 select 回潮”。
- **验收**：
  - 代码扫描：产品 UI 中不得出现原生 `<select`；
  - 设置/工作台不得存在连续 3 行以上的 switch 列表；
  - 权限中心可从三个导航壳层直接进入，并在 1440/800/480 下通过截图验收。
