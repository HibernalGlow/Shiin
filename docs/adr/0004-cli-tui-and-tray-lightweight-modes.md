# ADR-0004: 多入口轻量运行模式（GUI / 托盘后台 / CLI 命令行 / TUI 终端界面）

- **状态**：提议中 (Proposed)
- **日期**：2026-10-19
- **相关方**：Shiin 开发组 / 最终用户

---

## 背景与问题

游戏玩家在实际使用截图工具时存在多种场景偏好：
1. **完整桌面 GUI 模式**：需要直观调整配置、校准按键、查看截屏通知。
2. **托盘轻量常驻模式**：游戏过程中不希望有窗口占用任务栏或屏幕，希望开机静默启动、在托盘区小图标驻留，支持后台热键/手柄截屏，并能通过托盘菜单快速启停与打开目录。
3. **CLI 命令行模式**：自动化脚本或玩家希望在终端直接执行一条命令完成特定窗口或屏幕的截屏，或快速查询已连接的游戏手柄。
4. **TUI 终端交互模式**：开发者或无头/轻量环境下，在终端里直接监控手柄轴、按键、十字键实时输入数值与触发状态，而无需启动占用资源较大的图形界面。

## 决策

我们决定在同一仓库中支持四种使用形态，统一由 `src/core/` 驱动：

1. **GUI 桌面完整模式**：
   - 默认模式：通过 Electron 打开 React 自绘窗口，提供完整的交互式配置面板与手柄测试器。
2. **托盘轻量模式 (`--tray` / `minimizeOnStartup`)**：
   - 支持启动参数 `--tray` 或通过设置项「开机最小化到托盘」；
   - 启动时不创建或直接隐藏主窗口，仅保留 Tray 托盘图标；
   - 托盘右键菜单包含：`打开截图文件夹`、`开始监听 / 停止监听`、`显示主界面`、`退出`；
   - 托盘图标随监听状态动态切换（闲置图标 vs 监听中图标）。
3. **CLI 命令行模式 (`bin: shiin`)**：
   - 入口为 `src/app/cli/index.ts`，支持纯命令行调用：
     - `shiin capture [--screen <id>] [--window <id>] [--path <path>] [--format <png|jpg>]`：执行单次即时截图并输出保存路径；
     - `shiin devices`：列出当前连接的所有 SDL2 手柄设备、轴数、按键数；
     - `shiin listen`：无窗口后台监听手柄组合键。
4. **TUI 终端监控模式 (`shiin tui`)**：
   - 基于 OpenTUI（`@opentui/core` 与 `@opentui/react`）构建，保持与 Xaihi CLI 终端生态的技术栈对齐；
   - 终端仪表盘：利用 OpenTUI 终端渲染与组件化交互（`<box>`, `<text>`, `useKeyboard` 等），实时渲染：
     - 当前活动手柄型号、连接状态与设备能力；
     - 实时按键/轴/十字键状态指示；
     - 截屏与 OBS 回放触发历史日志与状态卡片；
     - 快捷交互：键盘或鼠标支持快捷切换监听、即时截屏与退出。

## 权衡与后果

- **正面**：满足从极简玩家（托盘轻量）到极客/脚本自动化（CLI/TUI）以及普通用户（完整GUI）的全部诉求；OpenTUI 使得 TUI 与 React 前端在心智模型和组件范式上保持高度一致。
- **代价**：增加了 `@opentui/core` 与 `@opentui/react` 依赖，但两者均为纯正终端 UI 方案，完全公开可获取。
