## 背景与问题

Shiin 目前的桌面端和 Xaihi 面板仍以早期 MD3 / MD3 Expressive 壳层为主：

- 壳层、标题栏、侧栏、节点面板和按钮共享 `src/ui/md3e.tsx` 的旧 token 与组件语法；
- 默认的深色青柠配色、标准卡片边界和统一圆角已经成为视觉主角，无法体现 Shiin 的截图、手柄和摄影器材语境；
- 当前实现把“Expressive”理解成换色、随机形状和圆角变化，页面构图仍接近后台模板；
- [ADR-0002](./0002-frontend-react-migration-and-md3-expressive.md)、[ADR-0007](./0007-expressive-controls-and-selects.md)、[ADR-0013](./0013-tonal-palette-from-single-seed.md) 中关于 MD3 的视觉约束需要重新评估。业务功能、React 技术栈、Xaihi 节点契约和共享核心不因本 ADR 改变。

用户要求彻底重写 UI，旧 MD3 视觉不得继续作为默认外观。用户指定使用 Oil UI 的方向探索流程，先比较三套首屏方向，再选定一套进入完整实现。

## 产品识别与设计基线

### 品类与主要任务

Shiin 是桌面截图与即时回放工具，属于高频使用的创作工具 / 游戏辅助工具。用户打开首屏主要做三件事：

1. 立即截图；
2. 查看手柄、监听和捕获管线是否就绪；
3. 在需要时处理权限、保存目录、组合键和 OBS 回放。

首屏应先让用户看到“现在能不能按下快门”，再让用户进入完整配置。配置和权限是工作流的一部分，不能被放在装饰性的介绍之后。

### 参考项目提取的关系

从 Inkloom、HibernalGlow CV 与 Rhythm 参考项目中保留以下关系：

- 首屏由一个清楚的主动作承担焦点，大字只服务于当前任务；
- 内容直接落在纸面或场景上，避免一层层相同的卡片；
- 圆角按角色变化，连接式控件用外圆角 + 内小圆角表达“接合”；
- 形状、颜色和动效是独立轴，同类控件保持一致，不把一个形状复制到整页；
- 反馈沿同一条路径传递：按下快门、捕获完成、文件写入和提示应形成一个连续动作；
- 字体与间距优先保证中文长标题、状态说明和数字在实际窗口中可读。

### 配色参考的可用信息

| 角色 | 色值 | 在 Shiin 中的用途 |
| --- | --- | --- |
| 荧光青柠 | `#C8F000` | 主快门动作、快门球与选中关键状态 |
| 橄榄卡其 | `#62652F` / `#85864A` | 器材语境、次级状态、导航选中指示 |
| 暖米白 | `#F2F0E8` | 工作台纸面底色 |
| 沙色 | `#E6E3CD` / `#D0C6AD` | 次级容器、连接组与已完成状态 |
| 装备墨灰 | `#343831` | 正文、高对比状态与浮动反馈 |
| 领带暗红 | `#A72D3B` | 错误、缺失权限与危险操作 |

以上颜色已随方向 A 采纳；正文、容器、描边、禁用态和深浅背景上的配对色由 `src/ui/expressive-theme.ts` 统一定义。Oil UI 是设计参考与工作流程，不是产品品牌；界面仍使用 Shiin 名称，不出现技能名称和内部方案名称。

## Rhythm 参考与最终三档架构（2026-10-22 已落地）

### 用户最新约束与修正

- **只有移动端（`< 600px`）才使用底部双区 Dock**；平板端（`600px–1199px`）与桌面端（`>= 1200px`）必须使用各自独立的导航形态与空间编排，不能在桌面或平板上套用移动端悬浮底栏。
- **主页恢复并升级 Material 3 Expressive 12 列非对称 Bento 架构**：否定将主页退化为一行普通 `<h1>` 加三等分挤压卡片的做法；恢复原版广受认可的 **8:4 非对称 Bento 英雄舞台**（左侧 `.sb-capture-hero` 展示状态药丸、60px 大号主快门 CTA、连接式快捷动作组与右侧 204px 可变形几何快门球 `.shiin-orb-stage`；右侧 `.sb-hero-session` 展示 64px 可变形手柄状态球与捕获管线回读）+ **4 卡弹性指标带（`.sb-metric-carousel`）** + **7:5 非对称配置与输入测试矩阵**。
- **权限继续收纳在设置页内（`PermissionSettings.tsx`）**：不单独拆出第三个顶级权限 Tab。

### 三档独立导航与工作台架构

| 视口档位 | 导航与全局动作形态 | 主页（工作台）空间编排 | 设置页空间编排 |
| --- | --- | --- | --- |
| **桌面端（`>= 1200px`）** | **顶栏内嵌分段胶囊（`TitleBar.tsx` `.shiin-desktop-nav`）**：将 `[工作台 \| 设置]` 弹簧胶囊与快捷快门内嵌进 52px 顶栏中央，零额外纵向/横向通栏占用 | **12 列非对称 Bento 舞台**：`8:4` 英雄快门舞台与手柄连接舱 + 4 列弹性指标卡（hover `1.18fr`）+ `7:5` 画面捕获与输出 / 触发组合 + `7:5` 三列色相自动化开关 / 实时按键摇杆测试器 | `7:5` 形状实验室与会话策略并排 + `6:6` 启动托盘与快门声音并排 |
| **平板端（`600px–1199px`）** | **左侧 88px Expressive 导航轨（`CaptureDock.tsx` `.shiin-tablet-rail`）**：顶部 64px 独立可变形快门 FAB + 中部 `[工作台 / 设置]` 56×34px 指示胶囊 + 底部连接式快捷工具栈（监听/回放/目录） | **双栏工作室（2-Pane Split Studio）**：横屏（`900–1199px`）主英雄卡与手柄舱 `7:5` 并列、配置与测试双栏并排同屏操作；竖屏（`600–899px`）英雄卡满宽展开、下方双列指标与紧凑双栏卡片 | 左侧导航轨常驻，右侧双列成组卡片，形状实验室双栏展开 |
